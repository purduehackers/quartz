Umami is hosted on Vulcan at [https://umami.purduehackers.com](https://umami.purduehackers.com).
Right now it’s running under Docker Compose as `kian` but at some point I wil migrate it to `hackers`.
# Organization
Umami supports team and user scopes for websites, so we can use it for Purdue Hackers websites, and can also let members use it for their own websites.

## Adding a user to the Purdue Hackers team (organizers)
### Generating the access code
The Purdue Hackers websites belong to the “Purdue Hackers” team in Umami, so that multiple users can manage them. To add a user to the team,
1. enter the admin interface,
2. select **Teams** in the sidebar,
3. select **Purdue Hackers,**
4. and copy the **Access code** and give this to the user you want to add.
