Room 280N BHEE
## Using the Makerspace:
You can come in during the times listed in the #makerspace channel in Discord, or during hack nights. Ping @Neel if you need to be let into the HIVE.  
## Rules:
1. **Be reasonable**
2. **Tools must stay in the makerspace**
	If you need to borrow tools, ask.
3. **You can only use the makerspace when I (Neel) or another organizer is in the makerspace **
4. **Clean up after yourselves**
	If you are leaving the makerspace for more than 30 minutes, put away tools and equipment. (If you need to store projects → <mention-page url="https://app.notion.com/p/3f9181f3b6ed8057aa9ff0bef511a040#3fa181f3b6ed800c98eccc3557e0bfff">Storing Projects</mention-page> )
5. **If you are using the Dremel or drill, wear safety glasses**
## 3D printing
[https://print.purduehackers.com/](https://print.purduehackers.com/)
Currently only PLA and some PETG. You can bring in your own filaments (TPU, ABS, ASA), but you need to ask Neel.
H2D Pro: 
- Max print size: 320 x 320 x 325mm
- Dual nozzle(2 material) + AMS (multicolor)
- Enclosed
## Storing Projects
We have storage lockers that you can store projects in. Ask Neel to use one.
