# Integrations
Currently, we have three planned:
1. Passports
2. Discord
3. GitHub
Although users can sign up with either one of those, we will make it so that a single account can have multiple integrations. For example, someone who signed up with Discord and add a passport or link a GitHub account which become valid forms of login for that account.
